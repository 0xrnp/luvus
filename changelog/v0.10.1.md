This release adds global scrollback search, safer agent resume options, live detection updates, and Quattro Rally. It is fully compatible with v0.10.0.

## Features

- **Search:** Search every pane's retained scrollback and jump directly to a matching line ([`3303b91`](https://github.com/RizRiyz/bohay/commit/3303b9127e443f0924f7e6541f9093f6c48c2fc1), [#33](https://github.com/RizRiyz/bohay/pull/33)).
- **Agents:** Optionally replay each pane's original CLI flags when resuming its session ([`3303b91`](https://github.com/RizRiyz/bohay/commit/3303b9127e443f0924f7e6541f9093f6c48c2fc1), [#33](https://github.com/RizRiyz/bohay/pull/33), [`2d83b7a`](https://github.com/RizRiyz/bohay/commit/2d83b7a501d785f0320b296a89fd76367563f0a0), [#32](https://github.com/RizRiyz/bohay/pull/32)).
- **Delegation:** Use `$name`, `$pane-id`, or `$agent-kind` in a prompt to hand work to another agent ([`bc30949`](https://github.com/RizRiyz/bohay/commit/bc3094902774980e45dcb359dccc1098f29640e9)).
- **Detection:** Update agent detection manifests without installing a new bohay release ([`7edf54a`](https://github.com/RizRiyz/bohay/commit/7edf54a630d3a482065388d2640ac78b5d8a0aec), [#34](https://github.com/RizRiyz/bohay/pull/34)).
- **Themes:** Add Quattro Rally, a soft dark theme with a rally-gold accent ([`c427926`](https://github.com/RizRiyz/bohay/commit/c4279266ae830cff00664919f4a8ca04fd03d0a5)).

## Improvements

- **Themes:** Make Quattro Rally the default for fresh installs without changing existing selections ([`3303b91`](https://github.com/RizRiyz/bohay/commit/3303b9127e443f0924f7e6541f9093f6c48c2fc1), [#33](https://github.com/RizRiyz/bohay/pull/33)).

## Fixes

- **Detection:** Recognize newer Claude Code builds as working after their spinner and interrupt hint changed ([`7edf54a`](https://github.com/RizRiyz/bohay/commit/7edf54a630d3a482065388d2640ac78b5d8a0aec), [#34](https://github.com/RizRiyz/bohay/pull/34)).
- **Website:** Add Quattro Rally to the theme picker with colors matching the app ([`3303b91`](https://github.com/RizRiyz/bohay/commit/3303b9127e443f0924f7e6541f9093f6c48c2fc1), [#33](https://github.com/RizRiyz/bohay/pull/33)).
