This release adds agent-to-agent delegation, clickable pane links, adaptive tab widths, and new Sky and pixtui experiences. It is fully compatible with v0.9.7.

## Features

- **Agents:** Delegate tasks by name, pane id, or kind, with bundled skills for Claude Code, Codex, and opencode ([`f34bbc2`](https://github.com/RizRiyz/bohay/commit/f34bbc22ea468d45ff2ab6351fb4d90109f31f3d), [#31](https://github.com/RizRiyz/bohay/pull/31)).
- **Changelog:** Open commit and PR references in the browser and keep only the three latest releases in the popup ([`6a8333b`](https://github.com/RizRiyz/bohay/commit/6a8333bb7952fa125fe9cc24857b9ae508dff284)).
- **Panes:** Ctrl+click URLs, domains, and existing file paths, including paths with line numbers ([`18d4851`](https://github.com/RizRiyz/bohay/commit/18d48516fb68ade4588152e42f9e462b7ac6cf2e)).
- **Tabs:** Size tabs to their names while keeping close buttons aligned and focus stable ([`19def4e`](https://github.com/RizRiyz/bohay/commit/19def4e3a67ed2072185e7972c235b876fd817fb), [#30](https://github.com/RizRiyz/bohay/pull/30)).
- **Themes:** Add the light Sky theme to bohay and bohay.dev ([`94721d6`](https://github.com/RizRiyz/bohay/commit/94721d64667cc7537951c585db94ae612d20d67e)).
- **Modules:** Add pixtui, a terminal pixel-art editor with layers, animation, and PNG/GIF export ([RizRiyz/pixtui](https://github.com/RizRiyz/pixtui)).

## Improvements

- **Menus:** Use Title Case across workspace, pane, agent, and file context menus ([`19def4e`](https://github.com/RizRiyz/bohay/commit/19def4e3a67ed2072185e7972c235b876fd817fb), [#30](https://github.com/RizRiyz/bohay/pull/30)).
- **Website:** Improve readability and reduce homepage image weight ([`a8ac4fd`](https://github.com/RizRiyz/bohay/commit/a8ac4fd988706dcbe4e6dfcfda0dbd60d74d9178)).
