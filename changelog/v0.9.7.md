Mission Control for your agents, right-click menus for module dock rows, resizable sidebars, and two new example modules. Fully compatible with v0.9.6, nothing to migrate.

### ✨ Added

- **Mission Control.** A `⠶ ctrl` tab per workspace listing every agent in that folder, running or resumable: status, tokens, context headroom and cost, totalled in the header. Click a row to jump to that agent or resume it; answer a blocked one inline. ([`9e20057`](https://github.com/RizRiyz/bohay/commit/9e2005786cd49842c726e812b1dea0bd50b4d7ac))

- **Modules can put a right-click menu on their own sidebar rows.** A dock row can offer several actions instead of one, declared per row, with dividers and destructive styling. See [Writing a Module](https://bohay.dev/docs/extend/writing-modules/#a-rows-own-right-click-menu). ([`ca896fb`](https://github.com/RizRiyz/bohay/commit/ca896fbc5da9be67d4d6cad4b570924941154739), [`405dbdf`](https://github.com/RizRiyz/bohay/commit/405dbdf25e077106b7a4b4824ef85d5f9b88a835))

- **Resizable sidebars.** Drag either sidebar's edge to set its width; it saves when you let go. ([`5ec0c59`](https://github.com/RizRiyz/bohay/commit/5ec0c596b0bc00f8a753b2aaaa3898f5ec8c6ed7), [#29](https://github.com/RizRiyz/bohay/pull/29))

- **An ESP-IDF example module.** Build, flash and monitor ESP32 boards from the sidebar. Flashing stops the serial monitor and brings it back in the same pane, so the log from before the flash survives. In `examples/modules/esp-idf`. ([`8d10569`](https://github.com/RizRiyz/bohay/commit/8d1056900699a32a22d91263e00e5c679642d266))

- **A Markdown slide-deck example module.** Present a Markdown file as slides in a pane. Pure Python stdlib, nothing to install. In `examples/modules/deck`. ([`8d10569`](https://github.com/RizRiyz/bohay/commit/8d1056900699a32a22d91263e00e5c679642d266))

- **Both example modules are listed on bohay.dev/modules.** ([`802dee6`](https://github.com/RizRiyz/bohay/commit/802dee6bcc1bdc90c23ddae5a7b5f07534f29457))

### 🔧 Changed

- **Cleaner sidebar text.** Long node, agent and branch names ellipsise instead of hard-cutting. ([`5ec0c59`](https://github.com/RizRiyz/bohay/commit/5ec0c596b0bc00f8a753b2aaaa3898f5ec8c6ed7), [#29](https://github.com/RizRiyz/bohay/pull/29))

- **Each sidebar holds up to three docks.** Extra docks stay off in Settings → Layout; moving one onto a full side is refused rather than silently dropped. ([`f9a22a6`](https://github.com/RizRiyz/bohay/commit/f9a22a63213daa01b593bf8de9e5cd23afa4b2dc))

### 🐛 Fixed

- **Agents no longer look stuck on "working" when idle.** A line padded with the invisible braille blank character read as a spinner. ([`21b1576`](https://github.com/RizRiyz/bohay/commit/21b1576aaec8af4948255c9abd5b8bb8e2427b85))

- **An idle agent no longer flashes "working" when you switch tabs.** The resize makes the agent repaint, and a reflowed line briefly read as a spinner. ([`70b3db8`](https://github.com/RizRiyz/bohay/commit/70b3db8b8752a437a42b63a98e389b2a2ebba5fc))

- **Agents now show up on WSL and musl/Alpine Linux.** The process tree is read from `/proc` instead of `ps`, which on those systems is a busybox build that can't report process parentage. ([`77a8f63`](https://github.com/RizRiyz/bohay/commit/77a8f63ad0fbb0100e79d9ff010fce546d7e9c61))

- **File viewer: long-line files scroll all the way down.** Scrolling counted file lines rather than the rows they wrap onto, so a file of few but very long lines stopped a line or two in. ([`e1a4a67`](https://github.com/RizRiyz/bohay/commit/e1a4a6725676e70ebf5a86b4f45d91d68c159801))

- **File viewer: the git change bar sits at the gutter's edge**, not between the line number and the code. ([`e1a4a67`](https://github.com/RizRiyz/bohay/commit/e1a4a6725676e70ebf5a86b4f45d91d68c159801))

- **Docs: the "On this page" list no longer cuts words off.** Entries wrapped wider than the column they were drawn in, losing whole words mid-phrase. ([`802dee6`](https://github.com/RizRiyz/bohay/commit/802dee6bcc1bdc90c23ddae5a7b5f07534f29457))

- **Docs: no empty gutter beside the page contents, and the article sits centred.** Half of every extra pixel of window width was going nowhere, about 19rem of dead space at 1920px. ([`802dee6`](https://github.com/RizRiyz/bohay/commit/802dee6bcc1bdc90c23ddae5a7b5f07534f29457))

- **Website: feature cards no longer overlap on mobile.** ([`3d35b10`](https://github.com/RizRiyz/bohay/commit/3d35b103c9b14e8540d89d0d98b6e3894d36edb2))
