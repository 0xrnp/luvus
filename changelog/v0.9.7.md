Resizable sidebars, a live Mission Control dashboard for a workspace's agents, right-click menus for module dock rows, two new example modules, and two fixes for agents that wrongly showed as "working". Fully compatible with v0.9.6, nothing to migrate.

### ✨ Added

- **Resizable sidebars.** Drag either sidebar's edge to set exactly how wide it is, the same way you already resize panes. The edge line brightens as you hover it so you can see it is draggable; grab it, drag left or right, and the new width is saved the moment you let go. It keeps your panes at least 24 columns wide and floors at a sensible minimum instead of collapsing, so you cannot drag a sidebar away by accident (that is still what the collapse toggle is for). The grab zone reaches a little onto the pane side for comfort but never over an agent that tracks the mouse, so a tool like Claude Code still gets its own edge clicks. Works on both the left and right sidebars. ([`5ec0c59`](https://github.com/RizRiyz/bohay/commit/5ec0c596b0bc00f8a753b2aaaa3898f5ec8c6ed7), [#29](https://github.com/RizRiyz/bohay/pull/29))

- **Modules can put a right-click menu on their own sidebar rows.** Until now a dock row from a module could only do one thing: whatever its single left-click action was. A row can now declare its own context menu, so a row that represents a *thing* (a device, a branch, a container) can offer several actions on it. Each entry runs one of the module's actions and is told which row it came from, so one script can serve the whole menu, and an entry can be marked destructive to render it in red. Dividers are supported, and an entry can carry its own payload so a single action can back a whole menu of variants rather than needing one action per entry. This is per row, not per dock, so in one sidebar section a device row can offer four actions while a plain command row below it offers none. Rows that don't declare a menu behave exactly as before, so every existing module is unaffected. The row you right-clicked is remembered when the menu opens, so a module that refreshes its dock on a timer can't cause a click to land on the wrong row. See [Writing a Module](https://bohay.dev/docs/extend/writing-modules/#a-rows-own-right-click-menu). ([`ca896fb`](https://github.com/RizRiyz/bohay/commit/ca896fbc5da9be67d4d6cad4b570924941154739), [`405dbdf`](https://github.com/RizRiyz/bohay/commit/405dbdf25e077106b7a4b4824ef85d5f9b88a835))

- **An ESP-IDF example module.** Build, flash and monitor ESP32 boards without leaving the terminal. The part worth having: flashing stops the serial monitor, reflashes, and brings the monitor back **in the same pane**, so the log from before the flash is still on screen next to what the board printed after it. That comparison is the actual work of embedded debugging, and every other workflow throws it away on each flash. The sidebar dock lists the boards it can see (click one to make it the active port) and groups the commands so they expand and collapse like the FILES tree, which keeps 29 commands behind five rows in a narrow sidebar. A chip row shows what the project is really configured for, read from its `sdkconfig` rather than from a setting, and turns red when the two disagree. `menuconfig` and the partition-table editor open in their own tabs, because they are terminal UIs and a multiplexer can simply let them be that. Lives in `examples/modules/esp-idf`, so copy it and change the id. ([`8d10569`](https://github.com/RizRiyz/bohay/commit/8d1056900699a32a22d91263e00e5c679642d266))

- **A Markdown slide-deck example module.** Present a Markdown file as slides in a pane: slides split on a `---` line, arrow keys or space to move, `r` to reload, `q` to quit. Headings, bold, italic, code, lists, blockquotes, fenced blocks, rules and links all render inline, and optional front matter sets the title. Pure Python standard library, so there is nothing to build and no presenter to install. Lives in `examples/modules/deck`. ([`8d10569`](https://github.com/RizRiyz/bohay/commit/8d1056900699a32a22d91263e00e5c679642d266))

- **The two new example modules are listed on bohay.dev/modules.** The ESP-IDF and Markdown deck examples now appear alongside the others, with their file and line counts read from the repo. ([`802dee6`](https://github.com/RizRiyz/bohay/commit/802dee6bcc1bdc90c23ddae5a7b5f07534f29457))

- **Mission Control: a live cost and status dashboard for a workspace's agents.** Right-click a workspace and choose **Open Mission Control** for a new tab that gathers every agent in that folder into one place: the ones you have running and the ones you can resume from disk. Each row shows the agent, where it lives, its live status, how many tokens it has spent, how full its context window is and how much headroom is left before it compacts (turning red as it gets close to losing history), and an estimated cost for the session; the header totals the cost across every session in the workspace, shows a running burn rate in dollars per hour, and turns red if a workspace passes a cost budget you set. Click any row to jump straight to that agent's pane, or to resume a session that is no longer running, so you never hunt through tabs to find the one that needs you. You can also act on an agent without leaving the dashboard: when one is blocked, the row shows the question it is waiting on and you can answer it inline, or interrupt, fork or close the agent, all with a single keypress. Press `o` for a full breakdown of the selected agent, and the list floats blocked and working agents to the top so what needs attention is always in view. Each row carries a context gauge that fills as the agent's window does, and a cost-by-model bar chart at the bottom shows at a glance where the spend goes. The token and cost figures are read quietly in the background from the agents' own session files (Claude today) and only while the tab is open, and an unchanged session is skipped rather than re-read, so nothing slows down when you are not looking. Costs are estimates from a built-in price table that you can override per model in your config. The tab is labelled `⠶ ctrl`. ([`9e20057`](https://github.com/RizRiyz/bohay/commit/9e2005786cd49842c726e812b1dea0bd50b4d7ac))

### 🔧 Changed

- **Cleaner sidebar text.** Long node, agent, and branch names end in an ellipsis instead of a hard cut. ([`5ec0c59`](https://github.com/RizRiyz/bohay/commit/5ec0c596b0bc00f8a753b2aaaa3898f5ec8c6ed7), [#29](https://github.com/RizRiyz/bohay/pull/29))

- **Each sidebar holds up to three docks.** A sidebar now takes at most three docks (six placed in total, three per side). Once a side is full it won't accept more, so any extra docks stay off in Settings → Layout for you to arrange to taste. Moving a dock onto a full side leaves it where it was and tells you the side is full, so nothing is dropped by surprise. ([`f9a22a6`](https://github.com/RizRiyz/bohay/commit/f9a22a63213daa01b593bf8de9e5cd23afa4b2dc))

### 🐛 Fixed

- **Agents no longer look stuck on "working" when they are idle.** An agent whose interface pads a line with the invisible braille blank character was read as showing a spinner. ([`21b1576`](https://github.com/RizRiyz/bohay/commit/21b1576aaec8af4948255c9abd5b8bb8e2427b85))

- **An idle agent no longer flashes "working" when you switch tabs.** Switching to a tab whose panes are a different size makes the agent repaint, and a reflowed line could read as a spinner for a moment. ([`70b3db8`](https://github.com/RizRiyz/bohay/commit/70b3db8b8752a437a42b63a98e389b2a2ebba5fc))

- **Agents now show in the sidebar on WSL and other Linux setups with a limited `ps`.** bohay reads the process tree straight from `/proc` instead of shelling out to `ps`, so an agent like opencode is recognised even on a musl or Alpine distribution whose `ps` is a busybox build that cannot report the process parentage detection relies on. ([`77a8f63`](https://github.com/RizRiyz/bohay/commit/77a8f63ad0fbb0100e79d9ff010fce546d7e9c61))

- **File viewer: long-line files can be scrolled all the way down.** A file with few but very long lines — a changelog whose paragraphs run to a thousand characters — could only be scrolled a line or two before it stopped, leaving most of the text unreachable. Scrolling counted file lines rather than the screen rows they actually wrap onto. ([`e1a4a67`](https://github.com/RizRiyz/bohay/commit/e1a4a6725676e70ebf5a86b4f45d91d68c159801))

- **File viewer: the git change bar sits at the edge of the gutter.** It was drawn between the line number and the code, splitting the two apart; it now runs down the left edge like an editor's change bar. ([`e1a4a67`](https://github.com/RizRiyz/bohay/commit/e1a4a6725676e70ebf5a86b4f45d91d68c159801))

- **Docs: the "On this page" list no longer cuts words off.** Entries wrapped to a width wider than the column they were drawn in, so long headings lost whole words mid-phrase rather than just their tails. ([`802dee6`](https://github.com/RizRiyz/bohay/commit/802dee6bcc1bdc90c23ddae5a7b5f07534f29457))

- **Docs: no more empty gutter beside the page contents, and the article sits centred.** The right column was pinned to a fixed width without telling the layout, so half of every extra pixel of window width went nowhere: about 4rem of dead space at 1440px and 19rem at 1920px. ([`802dee6`](https://github.com/RizRiyz/bohay/commit/802dee6bcc1bdc90c23ddae5a7b5f07534f29457))

- **Website: feature cards no longer overlap on mobile.** ([`3d35b10`](https://github.com/RizRiyz/bohay/commit/3d35b103c9b14e8540d89d0d98b6e3894d36edb2))
