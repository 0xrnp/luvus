Luvus is a rename and platform update from Bohay that adds a dedicated migration flow plus multi-client panes, memory-aware scrollback, and session management while preserving compatibility with existing Bohay-era state and commands.

## Features

- **Luvus:** Rename Bohay to Luvus in app, binary, crate, plugin, website, state directory, and extension contract, and migrate `~/.bohay` data to `~/.luvus` on first launch with compatibility fallbacks for legacy paths and env vars ([`a53ef1f`](https://github.com/RizRiyz/luvus/commit/a53ef1f), [#57](https://github.com/RizRiyz/luvus/pull/57)).
- **Migration:** Add `migrate.sh` to stop old and named servers, back up existing `~/.luvus`, and copy durable Bohay state to Luvus during upgrades with safe rollback behavior ([`a6670a8`](https://github.com/RizRiyz/luvus/commit/a6670a8), [#58](https://github.com/RizRiyz/luvus/pull/58)).
- **Sessions:** Add isolated named Luvus servers and full session lifecycle commands, including `--session` routing for named targets ([`1509da8`](https://github.com/RizRiyz/luvus/commit/1509da8), [#52](https://github.com/RizRiyz/luvus/pull/52)).
- **Panes and forks:** Move an active pane to another tab, reorder tabs, and fork supported Claude, Codex, or Pi sessions without losing context from the CLI ([`89e6bcf`](https://github.com/RizRiyz/luvus/commit/89e6bcf), [#41](https://github.com/RizRiyz/luvus/pull/41)).
- **Workspaces:** Rename and pin workspaces from the CLI and Codex plugin for faster context switching ([`0486f67`](https://github.com/RizRiyz/luvus/commit/0486f67)).
- **Views:** Give each connected client its own viewport so a background client does not resize the active terminal ([`5008048`](https://github.com/RizRiyz/luvus/commit/5008048), [#42](https://github.com/RizRiyz/luvus/pull/42)).
- **Delegation:** Delegate directly to a named agent without an `agent list` preflight from the Codex plugin and CLI ([`6bd64ba`](https://github.com/RizRiyz/luvus/commit/6bd64ba)).
- **Plugins:** Use the bundled Luvus plugin to control live workspaces, tabs, panes, and agents and to send Codex work to active sessions ([`7625f73`](https://github.com/RizRiyz/luvus/commit/7625f73), [#40](https://github.com/RizRiyz/luvus/pull/40)).
- **Terminal:** Add memory-aware scrollback with per-pane budgets plus keyboard copy mode with Shift+V selection ([`672e6d2`](https://github.com/RizRiyz/luvus/commit/672e6d2), [#46](https://github.com/RizRiyz/luvus/pull/46)).

## Improvements

- **CLI:** Add compact contextual help in command output to improve discoverability ([`eaf04c3`](https://github.com/RizRiyz/luvus/commit/eaf04c3), [#53](https://github.com/RizRiyz/luvus/pull/53)).
- **Server:** Answer API requests and wait operations without loop-tick latency for smoother responsiveness under load ([`ca8ea45`](https://github.com/RizRiyz/luvus/commit/ca8ea45), [#55](https://github.com/RizRiyz/luvus/pull/55)).
- **Terminal:** Reduce scrollback memory and render overhead and lazily allocate the VTE sync buffer for lower baseline costs ([`9619591`](https://github.com/RizRiyz/luvus/commit/9619591), [#54](https://github.com/RizRiyz/luvus/pull/54), [`a5acfad`](https://github.com/RizRiyz/luvus/commit/a5acfad), [#51](https://github.com/RizRiyz/luvus/pull/51)).
- **Codex plugin:** Use theme-aware composer backgrounds and contrast-safe branding across plugin surfaces ([`f3ee24b`](https://github.com/RizRiyz/luvus/commit/f3ee24b), [`1cc59b2`](https://github.com/RizRiyz/luvus/commit/1cc59b2)).
