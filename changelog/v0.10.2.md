This release adds terminal-matched colors, configurable tmux-style controls, Codex forks, clearer release notes, a refreshed homepage, and faster, more reliable pane handling. It is fully compatible with v0.10.1. Restart a running v0.10.1 server after upgrading.

## Features

- **Themes:** Match bohay to the terminal's foreground, background, and ANSI palette with a safe native fallback ([`01d9b57`](https://github.com/RizRiyz/bohay/commit/01d9b57a4d39787fc33172a21b717c7118fc144a), [#37](https://github.com/RizRiyz/bohay/pull/37)).
- **Agents:** Fork a Codex conversation into a new pane while the original keeps running ([`601799e`](https://github.com/RizRiyz/bohay/commit/601799e7d31924445c9a962ae3d25d2c66ce35a5)).
- **Delegation:** Update installed agent skills independently with `bohay skill update` ([`f19bfa9`](https://github.com/RizRiyz/bohay/commit/f19bfa976af627e5baccbbbc7425b8a5b7642530)).
- **Modules:** Add a complete agent skill for writing and debugging bohay modules ([`2887c9c`](https://github.com/RizRiyz/bohay/commit/2887c9c6d69ef9ebb00d23fd8fb9fc449e8fdb8a)).
- **Keys:** Configure the command prefix or switch to a tmux preset with familiar bindings ([`960878c`](https://github.com/RizRiyz/bohay/commit/960878c2316219a77182c550af23eef9c0a5c69f), [#38](https://github.com/RizRiyz/bohay/pull/38)).
- **Switcher:** Jump to tabs, workspaces, or agents from one searchable palette ([`960878c`](https://github.com/RizRiyz/bohay/commit/960878c2316219a77182c550af23eef9c0a5c69f), [#38](https://github.com/RizRiyz/bohay/pull/38)).
- **Sidebar:** Show agent-provided session titles in place of pane metadata ([`2e053e0`](https://github.com/RizRiyz/bohay/commit/2e053e0a351c3a51910189da9c07f669316b9294), [#35](https://github.com/RizRiyz/bohay/pull/35)).
- **Sidebar:** Pin workspaces and agents to the top of their lists ([`2e053e0`](https://github.com/RizRiyz/bohay/commit/2e053e0a351c3a51910189da9c07f669316b9294), [#35](https://github.com/RizRiyz/bohay/pull/35)).
- **Updates:** Check for a new release directly from the changelog popup ([`82b65b3`](https://github.com/RizRiyz/bohay/commit/82b65b37318c58e78c29cd3a7c33ab6d70cd679f)).
